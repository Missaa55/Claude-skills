# Roadmap

## Version 0.1 (current baseline)

- Portable review, debugging, and documentation skills
- Offline skill metadata validation and unit tests
- MIT licensing and contribution guidelines

## Version 0.2 (workflow integration)

- Workflow orchestrator skill and deterministic JSON tracker
- Tests for tracker invariants
- Architecture and reproducible quick-start

## Future candidates (not implemented)

- JSON Schema validation and richer stage dependency enforcement
- A benchmark dataset using synthetic tasks
- Skill evaluation harness comparing output quality across versions
- Optional integrations with agent clients behind explicit permission gates

No future feature should be described as shipped before implementation and verification.
