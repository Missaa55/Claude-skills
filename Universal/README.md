# Universal Skills

Reusable engineering guidance shared across Minecraft, application development and future domains.

Skills: task-planner, security-auditor, test-strategist, performance-profiler.

Existing core skills remain in `skills/`: change-reviewer, bug-investigator, documentation-auditor and workflow-orchestrator.

Run `python3 framework/route.py "review security of a minecraft server"` to see routing suggestions. This command only prints a plan; it does not execute agents.
