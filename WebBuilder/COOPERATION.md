# Cross-domain contracts

| Incoming task | Primary owner | Supporting skills | Exit evidence |
| --- | --- | --- | --- |
| Static business website | WebBuilder | Applications/web-frontend, Universal/test-strategist | Build, navigation, responsive and accessibility checks |
| Website with authentication | WebBuilder | Applications/backend-api, Applications/database-engineer, Universal/security-auditor | Authorization tests and deployment plan |
| SaaS application | AppBuilder | WebBuilder/design-system, Applications, Universal | End-to-end user journey tests |
| Minecraft community portal | WebBuilder | Minecraft/server-ops, Applications/backend-api | Safe server integration and permission review |

All handoffs use the same fields: goal, inputs, outputs, acceptance criteria, evidence, blockers, and approval requirements. An agent cannot treat another agent's unverified statement as a passed test. Blocking findings return to the owning implementation stage.
