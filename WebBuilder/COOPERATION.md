# Cross-domain contracts

| Incoming task | Primary owner | Supporting skills | Exit evidence |
| --- | --- | --- | --- |
| Static business website | WebBuilder | Applications/skills/web-frontend/SKILL.md, Universal/skills/test-strategist/SKILL.md | Build, navigation, responsive and accessibility checks |
| Website with authentication | WebBuilder | Applications/skills/backend-api/SKILL.md, Applications/skills/database-engineer/SKILL.md, Universal/skills/security-auditor/SKILL.md | Authorization tests and deployment plan |
| SaaS application | AppBuilder | WebBuilder/skills/webbuilder-design-system/SKILL.md, Applications, Universal | End-to-end user journey tests |
| Minecraft community portal | WebBuilder | Minecraft/skills/minecraft-server-ops/SKILL.md, Applications/skills/backend-api/SKILL.md | Safe server integration and permission review |

All handoffs use the same fields: goal, inputs, outputs, acceptance criteria, evidence, blockers, and approval requirements. An agent cannot treat another agent's unverified statement as a passed test. Blocking findings return to the owning implementation stage.
