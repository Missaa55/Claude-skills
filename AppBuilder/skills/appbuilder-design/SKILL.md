# AppBuilder Design

## When to use

Use when a product requires a new UI or a coherent redesign.

## Procedure

1. Establish target users, information architecture and representative journeys.
2. Define typography, spacing, colors, focus states and reusable components.
3. Document empty, loading, error and success states and responsive layouts.
4. Review keyboard navigation, labels, contrast and touch targets.
5. Do not use protected brand assets or unlicensed UI code.

## Output

Provide a token specification, component inventory, responsive behavior and measurable acceptance checks.
